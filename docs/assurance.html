How it's proven without trusting Vordr

Differential verification

vordr katreport prints each primitive's output over fixed public inputs. verify_crypto.py — Python stdlib only, no dependencies — recomputes every value with a self-validating pure-Python AES-GCM and checks the official FIPS/RFC/NIST vectors, then diffs. Now includes SHA-256 / BLAKE2b block-boundary lengths (55/56/63/64/127/128/129) — the padding edges most likely to expose a bug.

Findings from this pass

03

found & fixed by independent review + the tools built this pass

CRITICAL · OOB writeFIXED

ZIP-export central directory was unbounded

A vault with 512 or more attachment fields drove the export's record write past its fixed array straight into adjacent AES key-material — an out-of-bounds write of attacker-influenced bytes. A capacity guard now refuses the write and fails the export closed.

probe zexcap
DoS · pre-authFIXED

KDF cost parameters trusted before authentication

A crafted .vordr could set the Argon2 memory cost enormous; the KDF runs before the file MAC can be checked, so merely opening the file drove a giant allocation — no password needed. Now rejected as corrupt outside legitimate bounds.

probe kdfparam
DoS · hangFIXED

Infinite loop in the vordr.json parser

Found by a new structural fuzzer on its first run: a malformed decrypted JSON could stick the parse cursor so the loop never terminated. Fixed with forward-progress guards on both parse loops.

found by jfuzz
FIXED

Attachment-length integer wrap

A near-2⁶⁴ length could wrap past a plausibility check (post-auth; a downstream cap caught it, but fragile). Now the length is rejected before the arithmetic can overflow.

vault-open probes
FIXED

Double-free-safe secret allocator

The secure allocator wiped before releasing, so a stale/aliased free wrote freed pages — a recurring multi-vault crash class. A live-allocation registry makes any double, stale, or foreign free an inert no-op.

probe secfreedup

Vault export / import

04

new this pass — verified end-to-end, headless

ROUND-TRIP

Export a vault under a new password

Seals a chosen set of entries into a fresh child vault with its own salt + password, deduped by entry id (newer wins) so a re-merge is idempotent. The probe exports under a different password, reopens the child, and asserts every entry id survives.

probe vaultexportkat
ROUND-TRIP

Attachments carried into the child vault

Exports a vault holding two attachments, reopens the child under its new password, decrypts both blobs, and asserts the plaintext matches byte-for-byte — the ciphertext is carried verbatim, keyed by each attachment's own key that travels in the entry.

probe vaultexpattkat
